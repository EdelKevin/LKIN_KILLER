## Suggested application split

```
Tier S (10 cos)       high payoff + high reject rate → apply, but don't all-in
Tier A (15-20 cos)    main battlefield → most prep time + per-JD resume tailoring
Tier B (20-30 cos)    large NG class, higher hit rate → cast wide
Tier C (5-10 cos)     Forward-Deployed / small unicorns → backup + potential high equity
```

## Prep strategy

- **Primary**: LeetCode tag past-6-months for Tier S / A targets (best signal-to-noise)
- **Secondary**: LC Top Interview 150 for Tier B companies during interview cycles
- **Tier C (no tag)**: LC Top Interview 150 + Glassdoor reviews + company engineering blog
- **System design**: only for Tier S new-grad (Google L4, Meta E4, OpenAI MTS); intern roles rarely test it

## LeetCode tag access

LeetCode company tags require **Premium** ($35/mo or $159/year). For job-hunt season, 1–2 months of Premium pays off dramatically — buy it the week you start applying.
